Integritetspolicy

Senast uppdaterad: Februari 2026

Välkommen till Svenskt Korsord. Vi värnar om din integritet och vill vara transparenta med hur vi hanterar information på vår webbplats. Denna integritetspolicy förklarar vilken information vi samlar in, hur vi använder den och vilka rättigheter du har.

Sammanfattning: Vi samlar in minimalt med information. Dina spelframsteg sparas lokalt i din webbläsare. Du kan när som helst radera dina lokala data genom att rensa webbläsarens cache.

1. Vem är personuppgiftsansvarig?

Svenskt Korsord drivs som ett hobbyprojekt. Vi har inte en formell företagsstruktur utan är enskilda utvecklare som driver tjänsten. För frågor om integritet kan du kontakta oss via GitHub Discussions eller vår kontaktsida.

2. Information vi samlar in

Svenskt Korsord är en gratis tjänst för att spela korsord online. Vi har utformat tjänsten för att minimera insamling av personuppgifter. Här är en översikt över vilken information som kan samlas in:

2.1 Information du aktivt lämnar

Typ av information Beskrivning Syfte
Användarnamn för topplistan När du löser ett korsord kan du frivilligt ange ett namn (max 20 tecken) Visas på den delade topplistan
Speltid Hur lång tid det tog att lösa korsordet Rankning på topplistan

2.2 Automatiskt insamlad information

Typ av information Beskrivning Lagring
Spelframsteg Ifyllda bokstäver i korsordet Lokalt i din webbläsare (localStorage)
Inställningar Eventuella preferenser du gjort Lokalt i din webbläsare (localStorage)
Anonymiserad statistik Information för anti-fusk-systemet Lokalt i din webbläsare

2.3 Information via tredjepartstjänster

Vi använder tredjepartstjänster som kan samla in ytterligare information:

  • GitHub Pages: Vår webbplats hostas på GitHub Pages, som kan logga anonymiserade åtkomstdata

3. Cookies och lokal lagring

Vår webbplats använder följande typer av datalagring:

3.1 LocalStorage (lokal lagring)

Vi använder webbläsarens localStorage för att spara:

  • Dina spelframsteg så att du kan fortsätta där du slutade
  • Din senaste speltid och eventuellt användarnamn
  • Tidsstämpel för när du började spela

LocalStorage-data skickas aldrig till våra servrar automatiskt och lagras endast på din enhet.

5. Hur vi använder informationen

Vi använder insamlad information för följande ändamål:

  • Visa topplistan: Ditt valda användarnamn och speltid visas på den gemensamma topplistan
  • Spara framsteg: Dina ifyllda svar sparas lokalt så att du kan fortsätta spela senare
  • Förhindra fusk: Anonymiserad data används för att upptäcka misstänkt aktivitet på topplistan

6. Delning av information

Vi delar inte din personliga information med tredje parter, förutom:

  • Topplistan: Användarnamn och speltider visas publikt på topplistan för alla besökare
  • Rättsliga krav: Om vi skulle vara skyldiga att lämna ut information enligt lag

7. Dina rättigheter enligt GDPR

Enligt EU:s dataskyddsförordning (GDPR) har du följande rättigheter:

7.1 Rätt till tillgång

Du har rätt att begära information om vilka personuppgifter vi behandlar om dig. Eftersom vi lagrar minimalt med information och det mesta sparas lokalt i din webbläsare, kan du själv kontrollera detta genom webbläsarens utvecklarverktyg.

7.2 Rätt till radering

Du kan radera dina lokalt sparade data genom att:

  • Rensa webbläsarens cache och localStorage
  • Använda webbläsarens "rensa surfdata"-funktion
  • Använda webbläsarens privat/inkognito-läge

7.3 Rätt att invända mot behandling

Du kan:

  • Välja att inte ange ett användarnamn på topplistan
  • Använda annonsblockerare för att förhindra annonsrelaterade cookies
  • Välja bort personanpassade annonser via Googles inställningar

7.4 Rätt att klaga

Om du anser att vi behandlar dina personuppgifter på ett felaktigt sätt har du rätt att lämna in ett klagomål till tillsynsmyndigheten. I Sverige är detta Integritetsskyddsmyndigheten (IMY).

8. Datasäkerhet

Vi vidtar rimliga åtgärder för att skydda information:

  • Webbplatsen använder HTTPS för säker kommunikation
  • Känslig information lagras lokalt i din webbläsare, inte på våra servrar
  • Vi samlar inte in lösenord, betalningsinformation eller andra känsliga uppgifter

9. Barns integritet

Vår tjänst riktar sig inte specifikt till barn under 13 år. Vi samlar inte medvetet in personlig information från barn. Om du är förälder eller vårdnadshavare och tror att ditt barn har lämnat personlig information till oss, vänligen kontakta oss så att vi kan vidta lämpliga åtgärder.

11. Ändringar i denna policy

Vi kan uppdatera denna integritetspolicy från tid till annan. Eventuella ändringar kommer att publiceras på denna sida med ett uppdaterat datum. Vi rekommenderar att du regelbundet kontrollerar denna sida för eventuella ändringar.

12. Kontakt

Om du har frågor om denna integritetspolicy eller vill utöva dina rättigheter, kontakta oss via:

  • GitHub Discussions
  • Vår kontaktsida
