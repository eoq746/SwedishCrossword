Integritetspolicy

Senast uppdaterad: Mars 2026

Välkommen till Svenskt Korsord. Vi värnar om din integritet och vill vara transparenta med hur vi hanterar information på vår webbplats. Denna integritetspolicy förklarar vilken information vi samlar in, hur vi använder den och vilka rättigheter du har.

Sammanfattning: Vi samlar in minimalt med information. Dina spelframsteg sparas lokalt i din webbläsare. Om du väljer att logga in med Google eller Microsoft sparas ett anonymiserat användar-ID, ditt valda alias och din vänlista på servern. Du kan när som helst exportera dina uppgifter eller radera ditt konto via din profilsida. Lokala data raderas genom att rensa webbläsarens cache.

1. Vem är personuppgiftsansvarig?

Svenskt Korsord drivs som ett hobbyprojekt. Vi har inte en formell företagsstruktur utan är enskilda utvecklare som driver tjänsten. För frågor om integritet kan du kontakta oss via GitHub Discussions eller vår kontaktsida.

Det går även bra att kontakta oss via e-post på jockeb14@gmail.com

2. Information vi samlar in

Svenskt Korsord är en gratis tjänst för att spela korsord online. Vi har utformat tjänsten för att minimera insamling av personuppgifter. Här är en översikt över vilken information som kan samlas in:

2.3 Information via tredjepartstjänster

Vi använder tredjepartstjänster som kan samla in ytterligare information:

  • Google AdSense: Visar annonser till utloggade användare efter cookie-val. Vid "Acceptera alla" kan personanpassade annonser visas. Vid "Endast nödvändiga" används icke-personanpassade annonser (NPA).
  • Azure Container Apps: Vår webbtjänst körs på Microsoft Azure, som kan logga anonymiserade åtkomstdata

3. Cookies och lokal lagring

Vår webbplats använder följande typer av datalagring:

3.1 LocalStorage (lokal lagring)

Vi använder webbläsarens localStorage för att spara:

  • Dina spelframsteg så att du kan fortsätta där du slutade
  • Din senaste speltid och eventuellt användarnamn
  • Tidsstämpel för när du började spela

LocalStorage-data skickas aldrig till våra servrar automatiskt och lagras endast på din enhet.

3.2 Autentiseringscookie

Om du loggar in med Google eller Microsoft sätts en krypterad session-cookie (.Crossword.Auth) som håller dig inloggad i upp till 30 dagar. Cookien är HttpOnly och Secure – den kan inte läsas av JavaScript och skickas bara över HTTPS. Du kan logga ut när som helst via din profilsida, vilket raderar cookien.

3.3 Samtyckeshantering för annonser

När du besöker sidan första gången måste du välja mellan "Acceptera alla" och "Endast nödvändiga" innan du kan använda tjänsten. Innan valet görs laddas inga annonsskript.

  • Acceptera alla: Annonsskript kan laddas för personanpassade annonser.
  • Endast nödvändiga: Annonser visas i icke-personanpassat läge (NPA).
  • Inloggad användare: Vi visar inga annonser alls som en funktionell fördel med inloggning.

4. Google AdSense och tredjepartsannonser

Vi använder Google AdSense för att finansiera tjänsten. Google kan behandla teknisk information (t.ex. IP-adress, enhets- och webbläsaruppgifter) när annonser levereras.

Viktigt om annonser: Vid valet "Endast nödvändiga" använder vi icke-personanpassade annonser (NPA). NPA innebär mindre profilering, men kan fortfarande innebära begränsad användning av cookies eller andra identifierare för t.ex. frekvensbegränsning och bedrägeriskydd.

Läs mer om hur Google använder uppgifter när du besöker vår webbplats: Hur Google använder uppgifter när du använder våra partners webbplatser eller appar.

Du kan hantera dina annonsinställningar och välja bort personanpassade annonser via:

  • Googles annonsinställningar
  • Digital Advertising Alliance (DAA)
  • Your Online Choices (EU)

5. Hur vi använder informationen

Vi använder insamlad information för följande ändamål:

  • Visa topplistan: Ditt valda användarnamn och speltid visas på den gemensamma topplistan
  • Spara framsteg: Dina ifyllda svar sparas lokalt så att du kan fortsätta spela senare
  • Förhindra fusk: Anonymiserad data används för att upptäcka misstänkt aktivitet på topplistan
  • Visa annonser: Google AdSense visar annonser för utloggade användare baserat på valt samtyckesläge

6. Delning av information

Vi delar inte din personliga information med tredje parter, förutom:

  • Topplistan: Användarnamn och speltider visas publikt på topplistan för alla besökare
  • Annonspartners: Begränsad annonsrelaterad data kan behandlas av Google AdSense när annonser visas
  • Rättsliga krav: Om vi skulle vara skyldiga att lämna ut information enligt lag

7. Dina rättigheter enligt GDPR

Enligt EU:s dataskyddsförordning (GDPR) har du följande rättigheter:

7.1 Rätt till tillgång och dataportabilitet

Du har rätt att begära information om vilka personuppgifter vi behandlar om dig. Om du är inloggad kan du exportera alla dina serverlagrade uppgifter (statistik, poäng, alias, vänlista) i JSON-format via din profilsida. Lokalt sparade data kan du granska i webbläsarens utvecklarverktyg (localStorage).

7.2 Rätt till radering

Serverlagrade uppgifter: Om du är inloggad kan du radera hela ditt konto via din profilsida. Detta anonymiserar dina poäng och historik, tar bort ditt alias och alla vänrelationer, och loggar ut dig. Åtgärden kan inte ångras.

Lokalt sparade data: Du kan radera dina lokalt sparade data genom att:

  • Rensa webbläsarens cache och localStorage
  • Använda webbläsarens "rensa surfdata"-funktion
  • Använda webbläsarens privat/inkognito-läge

7.3 Rätt att invända mot behandling

Du kan:

  • Välja att inte ange ett användarnamn på topplistan
  • Välja att inte logga in — alla funktioner utom statistik, alias och vänner fungerar utan konto
  • Välja samtyckesläge för annonser via cookiebannern

7.4 Rätt att klaga

Om du anser att vi behandlar dina personuppgifter på ett felaktigt sätt har du rätt att lämna in ett klagomål till tillsynsmyndigheten. I Sverige är detta Integritetsskyddsmyndigheten (IMY).

8. Datalagring och gallring

Vi tillämpar följande lagringstider:

  • Topplistan (scores): Poäng äldre än 7 dagar gallras automatiskt
  • Historik: Spelhistorik äldre än 365 dagar gallras automatiskt. Vid radering av konto anonymiseras posterna omedelbart
  • Autentiseringscookie: Utgår automatiskt efter 30 dagar
  • Alias och vänrelationer: Sparas tills du raderar ditt konto

9. Datasäkerhet

Vi vidtar rimliga åtgärder för att skydda information:

  • Webbplatsen använder HTTPS för säker kommunikation
  • Inloggnings-ID:n hashas med SHA-256 — vi lagrar aldrig ditt riktiga Google/Microsoft-ID
  • Vi samlar inte in lösenord, betalningsinformation, e-postadresser eller andra känsliga uppgifter på servern

10. Barns integritet

Vår tjänst riktar sig inte specifikt till barn under 13 år. Vi samlar inte medvetet in personlig information från barn. Om du är förälder eller vårdnadshavare och tror att ditt barn har lämnat personlig information till oss, vänligen kontakta oss så att vi kan vidta lämpliga åtgärder.

11. Internationella dataöverföringar

Eftersom vi använder Google AdSense kan viss information överföras till servrar utanför EU/EES. Google använder standardavtalsklausuler och andra överföringsmekanismer enligt sina villkor.

12. Ändringar i denna policy

Vi kan uppdatera denna integritetspolicy från tid till annan. Eventuella ändringar kommer att publiceras på denna sida med ett uppdaterat datum. Vi rekommenderar att du regelbundet kontrollerar denna sida för eventuella ändringar.
