Riktlinjer för feedback

För att vi ska kunna hjälpa dig så effektivt som möjligt, försök inkludera följande information när du rapporterar problem:

  • Datum för det korsord där problemet uppstod
  • Vilken enhet och webbläsare du använder
  • En beskrivning av vad som hände och vad du förväntade dig
  • Skärmdumpar om det hjälper att förklara problemet

Vid förslag på nya ord, inkludera gärna en källa eller definition så att vi kan verifiera att ordet är korrekt.

Vanliga frågor (FAQ)

Innan du kontaktar oss, kolla om ditt svar finns bland våra vanliga frågor nedan:

När uppdateras korsordet?

Ett nytt korsord genereras automatiskt varje dag vid midnatt UTC (01:00 svensk vintertid, 02:00 sommartid). Om du vill ha ett nytt pussel, kom tillbaka imorgon!

Kan jag spela gamla korsord?

Just nu erbjuder vi endast dagens korsord. Vi planerar att lägga till ett arkiv med tidigare pussel i framtiden så att du kan gå tillbaka och spela korsord du missat. Håll utkik efter uppdateringar!

Hur fungerar topplistan?

När du löser korsordet kan du frivilligt ange ett namn för att visas på topplistan. Topplistan visar de 10 snabbaste tiderna för dagens korsord och delas mellan alla spelare. Den nollställs automatiskt vid midnatt när ett nytt korsord publiceras.

Varför markeras mitt resultat med en varning?

Vi har ett anti-fusk-system som upptäcker misstänkt aktivitet. Om ditt resultat markeras kan det bero på extremt snabba tider (under vad som är rimligt att uppnå), användning av utvecklarverktyg i webbläsaren, eller andra ovanliga mönster. Systemet är utformat för att säkerställa rättvis konkurrens på topplistan.

Fungerar sidan på mobilen?

Ja! Svenskt Korsord är responsivt designat och fungerar utmärkt på datorer, surfplattor och mobiltelefoner. Gränssnittet anpassar sig automatiskt efter skärmstorleken för bästa spelupplevelse.

Hur sparas mina framsteg?

Dina framsteg sparas lokalt i din webbläsare med hjälp av en teknik som kallas localStorage. Det innebär att dina ifyllda svar finns kvar även om du stänger webbläsaren eller datorn. Observera dock att om du rensar webbläsarens data eller cookies försvinner dina sparade framsteg.

Kan jag föreslå nya ord eller ledtrådar?

Absolut! Vi välkomnar bidrag från våra användare. Du kan skicka förslag via GitHub Discussions eller skapa en issue. Inkludera gärna en källa eller definition för nya ord så att vi kan verifiera dem.

Är tjänsten gratis?

Ja, Svenskt Korsord är helt gratis att använda. Vi visar annonser via Google AdSense för att täcka våra driftskostnader (serverhosting, domännamn, etc.), men det krävs ingen prenumeration eller betalning för att spela våra korsord.

Vad händer om jag hittar ett fel i korsordet?

Om du hittar ett felaktigt ord, en felaktig ledtråd eller ett tekniskt problem uppskattar vi om du rapporterar det via GitHub Issues. Beskriv felet så detaljerat som möjligt, inklusive datum för korsordet och vilken ledtråd/ord det gäller.

Varför finns det ibland ovanliga ord i korsordet?

Vår ordlista innehåller över 100 000 svenska ord, inklusive mer ovanliga termer, fackspråk, regionala uttryck och äldre ord.

Bidra till projektet

Svenskt Korsord är delvis öppen källkod. Om du är utvecklare och vill bidra till projektet är du välkommen att:

  • Forka repositoriet och skicka pull requests med förbättringar
  • Rapportera buggar och föreslå funktioner via GitHub Issues
  • Hjälpa till med att förbättra ordlistan och ledtrådarna
  • Översätta eller förbättra dokumentationen

Besök vårt GitHub-repository för att komma igång.

Feedback uppskattas

Din feedback är värdefull för oss! Berätta gärna vad du tycker om:

  • Svårighetsgraden på korsorden – är de för lätta, för svåra eller lagom?
  • Kvaliteten på ledtrådarna – är de tydliga och rättvisa?
  • Användarvänligheten på webbplatsen – är det lätt att navigera och spela?
  • Nya funktioner du skulle vilja se i framtiden
  • Eventuella problem du stött på

All konstruktiv feedback hjälper oss att göra Svenskt Korsord bättre!
